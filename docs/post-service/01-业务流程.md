# PostService 业务流程

本文档基于当前真实代码，描述各流程的目标、触发方式、处理步骤、涉及存储与验收点。

---

## 1. 发布帖子

| 项 | 说明 |
|----|------|
| **业务目标** | 用户发布图文帖子，进入 DB 并触发 Feed 侧写扩散 |
| **触发方式** | gRPC `CreatePost`（需 `x-user-id`）；Debug `POST /internal/debug/post` |
| **处理步骤** | 1. 校验 content / imageKeys → 2. Snowflake 生成 postId → 3. 事务写 posts + post_images + post_stats → 4. 回读 DB → 5. 写详情 Redis → 6. 写冷启动池 → 7. 异步好友 timeline 写扩散 |
| **数据表** | `posts`、`post_images`、`post_stats` |
| **Redis** | `yanshuqi:post:detail:{postId}`；`yanshuqi:feed:cold_start:pool:{male\|female}` |
| **验收点** | 返回 postId；DB 可查；冷启动池有记录；mvn test `PostWriteServiceTest` |

---

## 2. 查询帖子详情

| 项 | 说明 |
|----|------|
| **业务目标** | 展示帖子内容与实时点赞/评论数、是否已点赞 |
| **触发方式** | gRPC `GetPostDetail`；Debug `GET /internal/debug/post/{postId}` |
| **处理步骤** | 1. 读详情缓存 → 2. miss 则 DB 组装 → 3. 合并 `post_stats` + Redis delta → 4. 查 post_likes 得 isLiked |
| **数据表** | `posts`、`post_images`、`post_stats`、`post_likes`（isLiked） |
| **Redis** | detail cache；`stat:incr:*:likes/comments` |
| **验收点** | likeCount/commentCount 含未刷盘增量；caller 点赞后 isLiked=true |

---

## 3. 查询用户帖子列表

| 项 | 说明 |
|----|------|
| **业务目标** | 按用户分页浏览其历史帖子 |
| **触发方式** | gRPC `ListUserPosts`；Debug `GET /internal/debug/post/user/{userId}` |
| **处理步骤** | 1. postId 倒序游标分页查 posts → 2. 逐条组装详情与实时计数 |
| **数据表** | `posts`、`post_images`、`post_stats` |
| **Redis** | 计数 delta（读时合并） |
| **验收点** | cursor 分页；hasMore/nextCursor 正确 |

---

## 4. 删除帖子

| 项 | 说明 |
|----|------|
| **业务目标** | 作者逻辑删除帖子 |
| **触发方式** | gRPC `DeletePost`（需 `x-user-id`）；Debug `DELETE /internal/debug/post/{postId}` |
| **处理步骤** | 1. 校验作者 → 2. deleted=1, status=0 → 3. 驱逐详情缓存 |
| **数据表** | `posts`（逻辑删，保留 images/stats/互动历史） |
| **Redis** | 删除 detail key |
| **验收点** | 非作者 FORBIDDEN；删后 GetPostDetail POST_NOT_FOUND |

---

## 5. 点赞 / 取消点赞

| 项 | 说明 |
|----|------|
| **业务目标** | 幂等点赞/取消，计数实时可见 |
| **触发方式** | gRPC `ActionLike`；Debug POST/DELETE `.../like` |
| **处理步骤** | 1. 校验帖子存在 → 2. upsert post_likes → 3. 仅状态变化时 Redis likes delta ±1 → 4. 驱逐详情缓存 |
| **数据表** | `post_likes` |
| **Redis** | `stat:incr:{postId}:likes`、`updated_set` |
| **验收点** | 重复点赞不重复加计数；ActionLike success=true |

---

## 6. 创建评论

| 项 | 说明 |
|----|------|
| **业务目标** | 发表一级评论 |
| **触发方式** | gRPC `CreateComment`；Debug `POST .../comment` |
| **处理步骤** | 1. 校验帖子与 content → 2. 插入 post_comments → 3. ZSet 评论窗口 → 4. comments delta +1 |
| **数据表** | `post_comments` |
| **Redis** | `comments:{postId}` ZSet；comments delta |
| **验收点** | 返回 commentId；列表可见；计数 +1 |

---

## 7. 评论列表

| 项 | 说明 |
|----|------|
| **业务目标** | 帖子评论游标分页 |
| **触发方式** | gRPC `ListComments`；Debug `GET .../comment` |
| **处理步骤** | 1. 优先 Redis ZSet 窗口 → 2. 不足则 DB 回源 → 3. commentId 倒序分页 |
| **数据表** | `post_comments` |
| **Redis** | 评论窗口 ZSet（最新 200 条） |
| **验收点** | 仅未删除评论；cursor 分页 |

---

## 8. 删除评论

| 项 | 说明 |
|----|------|
| **业务目标** | 作者逻辑删除评论 |
| **触发方式** | gRPC `DeleteComment`；Debug `DELETE .../comment/{commentId}` |
| **处理步骤** | 1. 校验作者 → 2. deleted=1 → 3. ZSet 移除 → 4. comments delta -1 |
| **数据表** | `post_comments` |
| **Redis** | 评论窗口；comments delta |
| **验收点** | 非作者 FORBIDDEN；列表不再展示 |

---

## 9. 推荐 Feed

| 项 | 说明 |
|----|------|
| **业务目标** | 异性向推荐流，三路混排 + 已读去重 |
| **触发方式** | gRPC `GetRecommendFeed`；Debug `GET /internal/debug/post/feed` |
| **处理步骤** | 1. 取 caller 性别 → 读 recommend/timeline/cold_start → 2. 已读过滤 → 3. 槽位混排 → 4. 组装 PostInfo → 5. 写已读 Set |
| **Redis** | 热门池、冷启动池、timeline、read:posts |
| **验收点** | cursor `recOffset:csOffset`；第 3/6 位混排策略；删帖跳过 |

---

## 10. 计数刷盘

| 项 | 说明 |
|----|------|
| **业务目标** | 将 Redis 点赞/评论增量合并写入 post_stats |
| **触发方式** | LikeFlushJob / CommentFlushJob（每 60s，`@Profile("!test")`） |
| **处理步骤** | 1. 读 updated_set → 2. Lua 原子取 delta 归零 → 3. UPDATE post_stats → 4. idle 则移出 set |
| **数据表** | `post_stats` |
| **Redis** | delta keys、updated_set |
| **验收点** | `PostStatFlushJobTest`；刷盘后 delta 为 0 |

---

## 11. 热门池重建

| 项 | 说明 |
|----|------|
| **业务目标** | 近 3 天帖子按热度分重建 recommend 池 |
| **触发方式** | FeedScoreJob（每 5 分钟）；Debug `POST /internal/debug/post/feed/rebuild` |
| **处理步骤** | 1. 查近 3 天 posts → 2. 实时计数算分 → 3. 按作者性别写 tmp 池 → 4. rename 替换正式池 |
| **Redis** | `yanshuqi:feed:pool:recommend:{male\|female}` |
| **验收点** | `FeedPoolRebuildServiceTest`；手动 rebuild 后 Feed 有内容 |
