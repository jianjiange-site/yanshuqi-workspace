## 风险与后续计划

| 风险 | 缓解 / 计划 |
|------|-------------|
| Fallback 性别不准 | 接 user-service 后替换 UserProfileClient |
| timeline 为空 | 接好友关系后 fanout 自动生效 |
| 计数最终一致窗口 60s | 可缩短 Job 间隔或重要场景同步刷盘 |
| 已读 Set 内存增长 | 换 BloomFilter + TTL 已有 7 天 |
| gateway 未对接 | 下一阶段 gateway 注入 x-user-id 转发 gRPC |
