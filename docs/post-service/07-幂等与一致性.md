# PostService 幂等与一致性

## 1. 点赞幂等 `(user_id, post_id)`

**机制：**

- 表 `post_likes` 联合主键 `(user_id, post_id)`
- SQL：`INSERT ... ON CONFLICT DO UPDATE SET status=..., updated_at=...`
- `PostLikeManager.upsertIfChanged` 返回 **是否状态真实变化**

**重复操作：**

| 操作 | DB | Redis delta | 响应 |
|------|-----|-------------|------|
| 重复 LIKE | upsert 不变 | 不写 | success=true |
| 重复 UNLIKE | upsert 不变 | 不写 | success=true |
| LIKE→UNLIKE | status 0→1 或反向 | ±1 | success=true |

**为何联合主键：** 同一用户对同一帖最多一条记录，天然幂等，无需额外幂等表。

---

## 2. Redis delta + DB 基准值

```text
读路径：realCount = post_stats.count + Redis delta
写路径：互动成功 → INCR delta（不直接 UPDATE post_stats）
刷盘：Job 批量 UPDATE post_stats += delta，Lua 归零
```

**为何不直接高频 UPDATE post_stats：**

- 点赞/评论 QPS 高时，逐条 UPDATE 同一行锁竞争大
- Redis INCR O(1)，Job 60s 写合并，降低 DB 压力
- 用户读路径合并 delta，**感知上实时**

---

## 3. Lua 原子取数归零

**脚本逻辑（简化）：** GET → SET 0 → EXPIRE → return oldValue

**不能拆成客户端 GET + SET 0：**

刷盘期间若有新 INCR，SET 0 可能覆盖新增量 → **丢计数**。Lua 在 Redis 单线程原子执行，取走旧值后归零，期间新增 INCR 保留在新值中。

实现类：`PostStatDeltaRepository.ATOMIC_GET_AND_RESET`

---

## 4. 事务边界

| 操作 | DB 事务内 | 事务外 best-effort |
|------|-----------|-------------------|
| CreatePost | posts + images + stats | 详情缓存、冷启动池、fanout |
| DeletePost | soft delete | evict cache |
| ActionLike | upsert post_likes | Redis delta、evict cache |
| CreateComment | insert post_comments | ZSet、delta、evict |
| 刷盘 Job | UPDATE post_stats | Lua 读 Redis |

**原则：** PostgreSQL 提交成功即事实落地；Redis 失败 warn，不回滚 DB。

---

## 5. 评论与删帖一致性

- 删评论：逻辑删 DB + 移除 ZSet + delta -1，不物理删
- 删帖：逻辑删，Feed/详情读时 POST_NOT_FOUND 跳过
- 评论列表：只返回 deleted=0 且 status 正常

---

## 6. user-service Fallback

| 能力 | Fallback 行为 | 影响 |
|------|---------------|------|
| getGenderBucket | userId % 2 | Feed 分池仍可用 |
| getFriendUserIds | 空列表 | timeline 路为空，混排降级 recommend/cold_start |

不接真实好友关系 **不是 bug**，是当前阶段的显式降级。

---

## 7. Feed 已读与分页

- 已读 Set 写失败：warn，可能重复曝光
- cursor 仅跟踪 recommend/cold_start offset；timeline 靠已读 Set 去重
- 混排时同 postId 页内 dedupe

---

## 8. 一致性级别（面试表述）

| 维度 | 级别 |
|------|------|
| 点赞记录 | 强一致（DB 主键 + 事务） |
| 计数展示 | 最终一致（delta + 60s 刷盘） |
| 详情缓存 | 最终一致（evict + TTL） |
| Feed 池 | 最终一致（5min 重建 + 冷启动近实时） |
