## REST 接口检查

| 接口 | 检查点 |
|------|--------|
| GET /feed | callerUserId 来自 JWT，不传 userId |
| POST /swipe | LEFT/RIGHT |
| POST /super-hi | clientRequestId |
| GET /quota | 订阅档位 + 剩余 |
| GET /matches | matchId=biz_id，分页 |
| POST /visit/{id} | UPSERT |
| GET /visits | visitId=biz_id |
