# mobile-gateway 异常码与边界处理

## 1. 错误码分区

### 104xx 参数

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10400 | INVALID_ARGUMENT | 请求参数非法 |

### 105xx Token / Auth / 业务

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10501 | TOKEN_INVALID | access 无效 |
| 10502 | TOKEN_EXPIRED | access 过期 |
| 10503 | TOKEN_REVOKED | 已 logout 拉黑 |
| 10504 | REFRESH_TOKEN_REUSED | refresh 复用 |
| 10505 | REFRESH_TOKEN_DEVICE_MISMATCH | 设备不匹配 |
| 10506–10508 | REFRESH_TOKEN_* | refresh 无效/过期/撤销 |
| 10510 | USER_NOT_FOUND | 用户不存在 |
| 10511 | PERMISSION_DENIED | 无权限 |
| 10512 | TARGET_NOT_FOUND | 目标不存在 |
| 10513–10514 | POST/COMMENT_NOT_FOUND | 帖子/评论不存在 |
| 10520 | QUOTA_EXHAUSTED | 配额不足 |
| 10521 | INSUFFICIENT_COINS | 金币不足（来自 match gRPC） |

### 106xx SMS / 三方

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10601 | SMS_CODE_INVALID | 验证码错误 |
| 10602 | SMS_CODE_EXPIRED | 验证码过期 |
| 10603 | THIRD_PARTY_TOKEN_INVALID | 三方 token 无效 |
| 10604 | SMS_COOLDOWN | 发码过于频繁 |

### 107xx Payment not ready

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10701 | PAYMENT_SERVICE_NOT_READY | payment-service 尚未就绪 |

### 108xx IM / Call / Callback not ready

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10801 | IM_SERVICE_NOT_READY | im token 未就绪 |
| 10802 | CALL_SERVICE_NOT_READY | call token 未就绪 |
| 10803 | CALLBACK_SERVICE_NOT_READY | OpenIM callback 转发未就绪 |

### 109xx 上游

| Code | 枚举 | 说明 |
| ---: | --- | --- |
| 10901 | UPSTREAM_UNAVAILABLE | 上游不可用/超时 |
| 10902 | UPSTREAM_NOT_IMPLEMENTED | 上游能力未实现 |
| 10999 | （系统） | 未预期异常 → HTTP 500 |

## 2. gRPC → Gateway 映射表

见 `GatewayGrpcExceptionMapper.java`（详见 [05-REST到gRPC调用链.md](05-REST到gRPC调用链.md)）。

Post/Match 专用 NOT_FOUND 等会映射到 10510–10514（取决于下游 description）。

## 3. HTTP Status 约定

| 场景 | HTTP | Body |
| --- | ---: | --- |
| 无 JWT / token 无效 | **401** | `{"code":10501,"message":"...","data":null}` |
| 业务错误（含 not ready） | **200** | `Result.code` = 10701 等 |
| Bean Validation | **200** | 10400 |
| 未捕获系统异常 | **500** | 10999 |

**Payment/IM not ready 走 HTTP 200 + Result.code**，不是 503，便于 App 统一解析。

## 4. OpenIM Callback

返回 **`CallbackResponse` 直出**（非 Result）：

- prod/dev：`errCode=10803`
- mock/test：`actionCode=0` 占位

## 5. 边界原则

- prod **禁止** mock 支付/IM 数据（Profile 隔离 `!mock & !test`）。
- Controller 不捕获 gRPC 异常；统一 GlobalExceptionHandler。
- callerUserId **只来自 JWT**（callback 除外）。
