## 3. curl 手工验收（需启动 gateway + 下游）

### 3.1 设备登录

```bash
curl -X POST http://localhost:8080/api/v1/auth/login-device \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"dev-001","platform":1,"deviceModel":"iPhone","osVersion":"17","appVersion":"1.0.0"}'
```

### 3.2 Profile onboarding（带 token）

```bash
curl -X POST http://localhost:8080/api/v1/profile/onboarding \
  -H "Authorization: Bearer <accessToken>" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"Test","gender":1,"birthday":"2000-01-01"}'
```

### 3.3 Match quota

```bash
curl http://localhost:8080/api/v1/match/quota \
  -H "Authorization: Bearer <accessToken>"
```

### 3.4 Post feed

```bash
curl "http://localhost:8080/api/v1/post/feed?pageSize=10" \
  -H "Authorization: Bearer <accessToken>"
```

### 3.5 Payment coins → not ready（prod/dev）

```bash
# 无 token → 401
curl http://localhost:8080/api/v1/payment/coins

# 有 token → 10701
curl http://localhost:8080/api/v1/payment/coins \
  -H "Authorization: Bearer <accessToken>"
```

### 3.6 IM token → not ready

```bash
curl http://localhost:8080/api/v1/im/token \
  -H "Authorization: Bearer <accessToken>"
# 期望 Result.code=10801
```

### 3.7 OpenIM callback（无 JWT）

```bash
curl -X POST http://localhost:8080/callback/openim/callbackBeforeSendSingleMsg \
  -H "Content-Type: application/json" \
  -H "operationID: test-op-001" \
  -d '{"sendID":"10001","recvID":"10002","content":"hello"}'
# 期望 errCode=10803
```
