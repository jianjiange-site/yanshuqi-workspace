# mobile-gateway 鉴权与安全设计

## 1. JWT Access Token Claims

解析后写入 `JwtClaims` / `CurrentUserContext`：

| Claim | 说明 |
| --- | --- |
| userId | 业务用户 ID，**唯一可信来源** |
| jti | access token 唯一 ID，logout 黑名单用 |
| deviceId | 设备标识 |
| platform | 平台枚举（iOS/Android 等） |
| tokenVersion | 可选，预留踢下线 |
| expiresAtEpochSeconds | 过期时间 |

issuer：`dating-mobile-gateway`（`application-dev.yml` → `gateway.jwt.issuer`）。

## 2. Refresh Token 只存 Hash

- 明文 refresh **不落库**；仅存 SHA-256 hash（`auth_refresh_token.token_hash`）。
- 轮换时：旧 token 标记 `used_at`，新 token 新 jti + hash。
- 复用检测：已 used 的 refresh 再次提交 → `REFRESH_TOKEN_REUSED(10504)`。

## 3. 本地表（gateway schema）

### auth_device

设备登记：user_id + device_id + platform 唯一；记录 last_login_at、机型等。

### auth_refresh_token

refresh 链：token_hash、jti、expires_at、used_at、revoked_at、replaced_by_jti。

Flyway：`V20260623_001__create_gateway_auth_tables.sql`。

## 4. Redis 黑名单

| Key | 用途 | TTL |
| --- | --- | --- |
| `gateway:auth:blacklist:{jti}` | logout 后 access 失效 | 至 token 自然过期 |
| `gateway:auth:sms:{phone}` | 短信验证码 | 配置 300s |
| `gateway:auth:sms:cooldown:{phone}` | 发码冷却 | 配置 60s |

定义见 `AuthRedisKeys.java`。

## 5. SMS Mock 边界

- `gateway.sms.enabled=false`（dev 默认）：不真发短信，mock 码 `123456`。
- 生产需接真实 SMS 通道（当前未在本阶段实现）。

## 6. dev/test X-User-Id 兜底

- **仅 dev/test profile**：无 Bearer 时可读 `X-User-Id` header 构造临时 `JwtClaims`。
- **prod 禁止**：无 JWT 一律 401。
- 代码：`JwtAuthFilter.allowDevHeaderFallback()`。

## 7. OpenIM Callback 为何不走 JWT

- 调用方是 **OpenIM 服务端**，非 App 用户。
- 路径 `/callback/openim/**` 不在 `/api/v1/` 下，`JwtAuthFilter.shouldNotFilter` 直接跳过。
- 后续真实实现应由 im-service 验签；GW-5 仅契约占位。

## 8. Token 生命周期

| 事件 | 行为 |
| --- | --- |
| 过期 access | Filter 校验失败 → 401 / 10501 |
| 过期 refresh | refresh 接口 → 10507 |
| 撤销 refresh | logout → revoked_at |
| 复用 refresh | 10504，可选吊销整条链 |
| logout | access jti 进 Redis 黑名单 + refresh 撤销 |

## 9. 公开 vs 保护路径

**公开（/api/v1/auth 部分）**

- send-sms-code、login-device、login-phone、login-third-party、refresh

**保护（需 JWT 或 dev X-User-Id）**

- profile / upload / home / match / post / payment / im / call / logout

**完全跳过 JWT**

- `/health`、`/actuator/**`、`/callback/openim/**`
