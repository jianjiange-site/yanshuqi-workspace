# mobile-gateway 项目地图

## 1. 定位

**mobile-gateway** 是 Dating App 的 **移动端 BFF（Backend For Frontend）**：

- 对外：REST + Swagger，供 iOS/Android 调用。
- 对内：gRPC Client 转发到 user / match / post 等微服务。
- 本地持有：**JWT 签发与校验、refresh token 链、短信验证码 mock、设备登记**（gateway schema）。

不是纯路由网关：会做参数校验、VO/DTO 转换、鉴权、错误码映射，但 **不持有 user/match/post 业务数据**。

## 2. 已完成能力（GW-1～GW-5）

| 能力域 | 网关状态 | 说明 |
| --- | --- | --- |
| Auth + JWT | **已实现** | 设备/手机/三方登录、refresh 轮换、logout 黑名单 |
| Profile / Upload / Home | **已实现** | 资料 onboarding、头像 presign/confirm、Home card |
| Match | **已实现** | Feed / Swipe / SuperHi / Quota / Matches / Visit |
| Post | **已实现** | 发帖 / Feed / 点赞 / 评论 |
| Payment / Wallet | **契约占位** | 10 个 REST 入口；prod/dev 返回 10701 not ready |
| IM / Call / Callback | **契约占位** | token + OpenIM callback；prod/dev 返回 108xx not ready |

## 3. 不做什么

- 不做纯 HTTP 反向代理（无业务编排）。
- 不直连 user/match/post/payment/im **业务库**。
- 不维护 WebSocket / SSE（IM 长连接由 OpenIM SDK 负责）。
- **不在 gateway 实现真实支付 / OpenIM / LiveKit 业务**（GW-5 明确边界）。
- 不缓存下游业务数据（除 Auth 相关 Redis key）。

## 6. 代码入口

```text
mobile-gateway/src/main/java/com/dating/gateway/
├── controller/     # REST 入口（9 个业务 Controller + Health）
├── service/        # AuthService、*BffService
├── client/         # UserAuth/UserProfile/Post gRPC Client
├── service/        # MatchGrpcClient
├── security/       # JWT Filter / Issuer / Verifier / Blacklist
├── resolver/       # JwtCallerUserResolver
├── support/        # GatewayGrpcMetadataSupport、PaymentParamSupport
└── exception/      # GatewayErrorCode、GatewayGrpcExceptionMapper
```
