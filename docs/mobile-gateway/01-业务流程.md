# mobile-gateway 业务流程

按 **用户可感知流程** 描述，非按 Java 包堆叠。

---

## 1. 设备登录

| 项 | 说明 |
| --- | --- |
| 触发入口 | `POST /api/v1/auth/login-device` |
| 步骤 | ① App 传 deviceId/platform 等 → ② gateway 调 user-service `ResolveOrCreateDeviceUser` → ③ 登记 `auth_device` → ④ 签发 access + refresh JWT → ⑤ refresh hash 入库 |
| 下游 | user-service（gRPC 9091） |
| 数据流 | deviceId → userId；gateway 本地 auth 表 + Redis（可选黑名单） |
| 验收点 | 返回 accessToken/refreshToken；prod 无 JWT 不可访问业务接口 |

## 2. 手机号登录

| 项 | 说明 |
| --- | --- |
| 触发入口 | `POST /api/v1/auth/send-sms-code` → `POST /api/v1/auth/login-phone` |
| 步骤 | ① 发码（dev mock 123456）→ ② 验证码存 Redis → ③ 校验后调 user-service 解析用户 → ④ 签发 token |
| 下游 | user-service |
| 验收点 | 错误码 10601/10602；cooldown 10604 |

## 3. 三方登录

| 项 | 说明 |
| --- | --- |
| 触发入口 | `POST /api/v1/auth/login-third-party` |
| 步骤 | 校验 provider/token → user-service 解析或创建用户 → 签发 token |
| 下游 | user-service |
| 验收点 | 无效凭证 10603 |

## 4. Refresh Token 轮换

| 项 | 说明 |
| --- | --- |
| 触发入口 | `POST /api/v1/auth/refresh`（公开，不需 access JWT） |
| 步骤 | ① 校验 refresh hash + 设备匹配 → ② 标记旧 refresh used → ③ 签发新 token 对 → ④ 写 replaced_by_jti 链 |
| 下游 | 仅 gateway 本地 DB |
| 验收点 | 复用旧 refresh → 10504；设备不匹配 → 10505 |

## 5. Logout 黑名单

| 项 | 说明 |
| --- | --- |
| 触发入口 | `POST /api/v1/auth/logout`（需 Bearer JWT） |
| 步骤 | ① 解析 access jti → ② Redis `gateway:auth:blacklist:{jti}` → ③ 撤销 refresh |
| 下游 | Redis + gateway DB |
| 验收点 | 登出后旧 access 请求 401/10503 |

## 11. Payment Not Ready 流程

| 触发入口 | `/api/v1/payment/**`（需 JWT） |

## 12. IM Token Not Ready / Callback 占位

| 项 | 说明 |
| --- | --- |
| IM Token | `GET /api/v1/im/token` → prod/dev **10801** |
| Call Token | `POST /api/v1/call/token` → prod/dev **10802** |
| Callback | `POST /callback/openim/{cmd}` **无 JWT** → CallbackResponse errCode=10803 |
| 下游 | im-service 未就绪；真实 token 应由 im-service 调 OpenIM/LiveKit |
| 验收点 | callback 无 JWT 可访问；IM token 无 JWT → 401 |
