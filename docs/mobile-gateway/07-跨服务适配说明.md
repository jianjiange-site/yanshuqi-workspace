# mobile-gateway 跨服务适配说明

## 总览

| 服务 | 当前状态 | gateway 如何适配 | 风险 |
| --- | --- | --- | --- |
| user-service | **生产级 Auth/Profile gRPC 已就绪** | UserAuthGrpcClient + UserProfileGrpcClient | user 故障 → 无法登录/改资料 |
| match-service | **7 RPC 已就绪** | MatchGrpcClient；callerUserId 在 request | 配额/Feed 依赖 Redis+PG |
| post-service | **9 RPC 已就绪** | PostGrpcClient；caller 走 metadata | post 故障 → 发帖/Feed 不可用 |
| payment-service | **Stage 00-A 骨架，无 proto** | PaymentBffServiceImpl 返回 10701 | **不可写“支付已完成”** |
| im-service | **Stage 00-A 骨架，无 proto** | ImBffServiceImpl 返回 108xx | **不可写“IM 已完成”** |

---

## user-service

**已对接能力**

- Auth：`ResolveOrCreateDeviceUser` / `PhoneUser` / `ThirdPartyUser`
- Profile：`UpsertOnboarding`、`UpdateProfile`、`GetHomeCardProfile`
- Avatar：`PresignAvatarUpload`、`ConfirmAvatarUpload`

**Proto**

- `proto/user/user_auth_service.proto`
- `proto/user/user_profile_service.proto`

**适配要点**

- 登录：gateway 调 user 拿 userId，**JWT 在 gateway 签发**。
- 业务接口：callerUserId 只信 JWT，禁止信前端传的 userId（除 dev X-User-Id 兜底）。

---

## match-service

**已对接 7 RPC**

- GetTodayFeed、Swipe、SuperHi、GetQuota、ListMatches、RecordVisit、ListVisits

**Proto**：`proto/match/match_service.proto`

**适配要点**

- `caller_user_id` 写入每个 request message。
- SuperHi `client_request_id` **原样透传**（幂等键在 match-service）。
- gRPC 异常 → `GatewayGrpcExceptionMapper`（如 QUOTA_EXHAUSTED → 10520）。

---

## post-service

**已对接 9 RPC**

- CreatePost、GetPostDetail、DeletePost、GetRecommendFeed、ListUserPosts
- ActionLike、CreateComment、ListComments、DeleteComment

**Proto**：`proto/post/post_service.proto`

**适配要点**

- caller 身份走 **`x-user-id` metadata**（`GatewayGrpcMetadataSupport`）。
- post-service 从 metadata 取 caller，不信任 body 里的 userId。

---

## payment-service

**当前状态**

- `proto/payment/` 仅 `.gitkeep`
- payment-service 无业务 gRPC 实现

**gateway 适配（GW-5）**

- 10 个 REST 契约占位
- `PaymentBffServiceImpl`：`@Profile("!mock & !test")` → 10701
- `MockPaymentBffServiceImpl`：`@Profile({"mock","test"})` → mock 数据

**切换条件**

1. payment proto 定义 Coin/Payment/Subscription RPC
2. payment-service 实现 gRPC
3. gateway 新增 PaymentGrpcClient，替换 not ready

---

## im-service

**当前状态**

- `proto/im/` 仅 `.gitkeep`
- im-service 无业务 gRPC

**gateway 适配（GW-5）**

- IM token / Call token：10801 / 10802
- OpenIM callback：无 JWT，CallbackResponse 10803
- 真实 OpenIM/LiveKit secret **不应出现在 gateway**

**切换条件**

1. im proto（ImTokenService、CallbackForward 等）
2. im-service 对接 OpenIM/LiveKit
3. gateway BFF 改 gRPC 转发
