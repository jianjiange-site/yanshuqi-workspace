# mobile-gateway 配置启动与部署说明

## 1. 环境要求

- **JDK 21**（仓库验证使用 Eclipse Temurin 21）
- Maven 3.9+
- 可选依赖（dev 全功能）：PostgreSQL、Redis、Nacos、MinIO；user/match/post gRPC 进程

## 2. 启动命令

```bash
cd mobile-gateway
export JAVA_HOME=/path/to/jdk-21   # Windows 设置 $env:JAVA_HOME
mvn spring-boot:run
```

默认 REST 端口：**8080**。

健康检查：

- `GET http://localhost:8080/health`
- `GET http://localhost:8080/actuator/health`

## 3. Profile 说明

| Profile | 用途 |
| --- | --- |
| dev（默认） | 本地开发；SMS mock；允许 X-User-Id 兜底 |
| test | 单测；Mock Payment/Im Bff；排除部分 GrpcClient |
| prod | 禁止 X-User-Id；Payment/Im 返回 not ready |
| mock | 与 test 类似，Payment/Im 返回 mock 数据 |

**Payment/Im 实现切换**

- `PaymentBffServiceImpl` / `ImBffServiceImpl`：`@Profile("!mock & !test")`
- `MockPaymentBffServiceImpl` / `MockImBffServiceImpl`：`@Profile({"mock","test"})`

## 4. 关键配置（application-dev.yml）

| 配置项 | 说明 |
| --- | --- |
| `spring.datasource` | PostgreSQL schema `gateway` |
| `spring.data.redis` | 短信/黑名单 |
| `grpc.client.user-service` | static://127.0.0.1:**9091** |
| `grpc.client.match-service` | static://127.0.0.1:**9092** |
| `grpc.client.post-service` | static://127.0.0.1:**9094** |
| `gateway.jwt.*` | RS256 密钥、TTL |
| `gateway.sms.*` | mock 短信 |
| `gateway.grpc.deadline-seconds` | 5 |

JWT 密钥环境变量：

- `GATEWAY_JWT_PRIVATE_KEY_BASE64`
- `GATEWAY_JWT_PUBLIC_KEY_BASE64`

## 5. 下游 gRPC 端口

| 服务 | 端口 | gateway 是否已接 |
| --- | ---: | --- |
| user-service | 9091 | 是 |
| match-service | 9092 | 是 |
| post-service | 9094 | 是 |
| payment-service | 9095（规划） | **否** |
| im-service | 9096（规划） | **否** |

## 6. payment / im 未就绪说明

启动 gateway **不依赖** payment/im 进程。访问 Payment/IM 接口：

- prod/dev → 明确业务错误码 10701/108xx
- 不会静默成功或返回假数据

## 7. Docker

仓库 Stage 00-A 可能有 Dockerfile 占位；GW-6 不修改镜像。生产部署需：

- 注入 JWT 密钥、DB/Redis 连接
- 配置 user/match/post gRPC 地址（Nacos 或 static）
- **不要**在 prod 启用 mock profile
