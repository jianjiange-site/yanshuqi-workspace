# mobile-gateway 阶段复盘（GW-0～GW-6）

## GW-0：只读适配报告

- **做了什么**：梳理 mobile-gateway 与 Swagger/下游差距，确认 user/match/post 有 proto，payment/im 为骨架。
- **范围**：只读，无代码改动。
- **遗留**：明确 Payment/IM 不可假装完成。

## GW-1：Auth + JWT 鉴权闭环

- **做了什么**：AuthController、JWT 签发/校验、refresh 轮换、logout 黑名单、auth 表 Flyway、Sms mock。
- **验收**：AuthControllerTest、JwtAuthFilterTest 等通过。
- **边界**：JWT 在 gateway，不在 user-service。

## GW-2：Profile / Upload / Home

- **做了什么**：UserProfileGrpcClient、Profile/Upload/Home BFF + Controller、ProtoAdapter。
- **验收**：Profile/Upload/Home ControllerTest。
- **边界**：callerUserId 来自 JWT。

## GW-3：Match 生产化

- **做了什么**：MatchController 7 接口、MatchGrpcClient、参数校验、gRPC 异常映射、SuperHi clientRequestId 透传。
- **验收**：MatchControllerTest + JwtTest。
- **边界**：callerUserId 在 proto request。

## GW-4：Post BFF

- **做了什么**：PostController 10 接口、PostGrpcClient、x-user-id metadata、PostGrpcMetadataSupport。
- **验收**：91 tests（含 Post gRPC metadata 测试）。
- **边界**：metadata 传 caller，非 body。

## GW-5：Payment / IM 契约占位

- **做了什么**：Payment/Im Controller、BffService prod not ready + mock profile、OpenIm callback、GatewayGrpcMetadataSupport 抽取、错误码 10701–10803。
- **验收**：112 tests。
- **边界**：prod 不返回 mock；不写 payment/im proto。

## GW-6：文档 + 验收脚本（本阶段）

- **做了什么**：docs/mobile-gateway 12 文档、verify-gateway-final 脚本、README 更新。
- **范围**：无业务代码改动。
- **交付**：可面试/验收的完整文档索引。

## 当前遗留边界

1. payment-service / im-service 无正式 proto/gRPC。
2. Payment/IM prod/dev 仅 not ready + 契约。
3. OpenIM callback 未转发 im-service。
4. 全链路 curl 联调需启动 user/match/post + gateway。
5. SMS 生产通道、PayPal、真实 OpenIM 均未在 gateway 实现。

## 下一步建议

1. user + match + post + gateway 联调 curl 演示脚本。
2. payment/im proto 设计与服务实现。
3. gateway 替换 PaymentBffServiceImpl / ImBffServiceImpl 为 gRPC 客户端。
