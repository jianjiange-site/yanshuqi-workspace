# user-service 核心调用链复盘

> **阅读顺序**：4 / 9

按真实代码执行顺序整理。gRPC 层仅做参数转换，业务在 Service，单表访问在 Manager。

---

## Register

```
mobile-gateway / 调用方
→ UserAuthGrpcService.register()
→ RegisterRequest → RegisterCommand
→ UserAuthServiceImpl.register()
  → 1. validateRegisterCommand
  → 2. IdentityHashService 归一化 + hash（不写日志明文）
  → 3. UserAuthIdentityManager.findByIdentityTypeAndHash（幂等）
  → 4. BusinessIdGenerator 生成 userId/authId/profileId/settingId
  → 5. UserManager.createUser
  → 6. UserAuthIdentityManager.createIdentity（BCrypt password_hash）
  → 7. UserProfileManager.createDefaultProfile
  → 8. UserSettingsManager.createDefaultSettings
→ RegisterResult → RegisterResponse
```

**DB**：写 4 表。**Redis**：无。

---

## VerifyLogin

```
调用方
→ UserAuthGrpcService.verifyLogin()
→ VerifyLoginRequest → LoginCommand
→ UserAuthServiceImpl.verifyLogin()
  → 1. validateLoginCommand + 设备校验
  → 2. IdentityHashService 归一化 + hash
  → 3. UserAuthIdentityManager.findByIdentityTypeAndHash
  → 4. PasswordHashService.matches
  → 5. UserManager.findByUserId + 账号状态校验
  → 6. push_token → hash；device_fingerprint 规范化
  → 7. UserDeviceManager upsert
  → 8. UserManager.updateLastLoginAt + UserAuthIdentityManager.updateLastLoginAt
→ LoginResult → VerifyLoginResponse
```

**DB**：读 3 表，写 2 表。**Redis**：无。

## UpdateProfile

→ UpdateProfileRequest → UpdateProfileCommand
→ UserProfileServiceImpl.updateProfile()
  → 1. ProfileFieldValidator.validateAndNormalize

  → 3. UserProfileManager.findByUserId
  → 4. ProfileCompletionCalculator.calculate

→ UserProfileQueryServiceImpl.batchGetBasicProfiles()
  → 1. BatchUserIdsValidator（去重、1～100）
  → 2. UserProfileCacheService.getBasicProfiles（Redis basic）
  → 3. 未命中：UserManager.listByUserIds
           + UserProfileManager.listByUserIds
           + UserPhotoManager.listEnabledApprovedAvatarsByUserIds

  → 5. UserProfileCacheService.putBasicProfiles

## ResolveOrCreateDeviceUser / Phone / ThirdParty（USER-09-1）

```
mobile-gateway
→ UserAuthGrpcService.resolveOrCreate*()
→ ResolveOrCreate*Command
→ UserAuthServiceImpl.resolveOrCreate*()
  → 1. 参数校验（deviceId / phone / platform / smsCode / idToken）
  → 2. IdentityHashService 归一化 + hash
  → 3. UserAuthIdentityManager.findByIdentityTypeAndHash
  → 4. 首次：四表 create；并发 DuplicateKey → 重查 identity
  → 5. validateAccountStatus
  → 6. upsertUserDevice + updateLastLoginAt
  → 7. LoginPendingCalculator.computePending
  → 8. newlyCreated 时 UserCacheInvalidationService.evictProfileCache
→ ResolveOrCreateLoginUserResult → Response
```

**DB**：首次写四表；复登写 devices + last_login。**Redis**：仅首次创建删四类 key。
