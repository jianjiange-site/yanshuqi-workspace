## Redis

### Key 一览

| Key | 内容 | TTL | 写入时机 | 失效时机 |
|---|---|---|---|---|
| `yanshuqi:user:basic:{user_id}` | `BasicUserProfileVO` JSON | 600s | BatchGetBasicProfiles 未命中回源后 | UpdateProfile / BindUserPhoto |
| `yanshuqi:user:profile:{user_id}` | `RecommendUserProfileVO` JSON | 600s | BatchGetRecommendProfiles 未命中后 | 同上 |
| `yanshuqi:user:status:{user_id}` | `UserAvailableVO` JSON | 600s | CheckUserAvailable 未命中后 | 同上 |

配置：`app.user-cache.profile-ttl-seconds=600`（`UserCacheProperties`）。

### cache-aside 策略

1. 批量读 Redis（`CacheSafeExecutor.safeMultiGet`）。
2. 命中直接使用；未命中批量 IN 查 DB。
3. Service 层合并后 `put*` 写回 Redis。
4. **Redis 不是 source of truth**；写库成功后由 `UserCacheInvalidationService` 删 key。

### 降级策略

| 场景 | 行为 |
|---|---|
| get 失败 | warn 日志，视为全部 miss，回源 DB |
| set 失败 | warn 日志，不影响 gRPC 返回 |
| delete 失败 | warn 日志，不回滚 DB 事务 |
| 反序列化失败 | warn + 删除坏 key，回源 DB |

禁止：`FLUSHDB` / `FLUSHALL`、缓存 password/token/identity/完整 URL。

## 异常体系

### 核心类

- `UserBizException`：携带 `UserErrorCode`
- `UserGrpcStatusMapper`：errorCode → gRPC `Status`
- `UserGrpcExceptionAdvice`：全局转换，未知异常 → `INTERNAL_ERROR`（不泄露堆栈）

### gRPC Status 映射

| Status | 典型 errorCode |
|---|---|
| **INVALID_ARGUMENT** | `USER_REQUEST_INVALID`, `PROFILE_UPDATE_INVALID`, `PHOTO_OBJECT_KEY_INVALID`, `USER_BATCH_SIZE_EXCEEDED`, … |
| **UNAUTHENTICATED** | `PASSWORD_INVALID`, `IDENTITY_NOT_FOUND` |
| **PERMISSION_DENIED** | `USER_DISABLED`, `USER_BANNED`, `USER_DELETED` |
| **NOT_FOUND** | `USER_NOT_FOUND`, `PROFILE_NOT_FOUND`, `PHOTO_NOT_FOUND` |
| **ALREADY_EXISTS** | `IDENTITY_ALREADY_EXISTS` |
| **ABORTED** | `USER_CONCURRENT_CONFLICT` |
| **INTERNAL** | `INTERNAL_ERROR`、未识别异常 |

调用方看到的 `Message` 为 **errorCode 字符串**（如 `USER_BANNED`），非 Java 堆栈。

## 日志

### 成功日志（允许字段）

| 场景 | 字段 |
|---|---|
| 注册 | `userId`, `identityType` |
| 登录 | `userId`, `identityType` |
| 资料更新 | `userId`, `profileScore`, `profileStatus` |
| 照片绑定 | `userId`, `photoType`, `photoId` |
| 批量查询 | `method`, `userIdsSize`, `cacheHit`, `cacheMiss`, `costMs` |

### 异常日志

- gRPC：`errorCode`、异常类型名（未知异常）
- 不打印完整 request body

### 慢调用日志（SlowCallLogger）

- 阈值：**500ms**（可配置 `slow-call-threshold-ms`）
- 覆盖：`register`, `verifyLogin`, `updateProfile`, `bindUserPhoto`, 三个批量查询
- 字段：`method`, `costMs`, `success`, `errorCode`, `userId` 或 `userIdsSize`

### 禁止打印

`password`, `password_hash`, `identity_value` 明文, `identity_hash`, 完整手机号/邮箱, `token`, `JWT`, `device_fingerprint`, `push_token`, `AK`, `SK`, `Secret`, 完整图片 URL。

脱敏工具：`LogMaskUtil`, `SensitiveLogUtil`。
