## Redis

### Key 一览

| Key | 内容 | TTL | 写入时机 | 失效时机 |
|---|---|---|---|---|
| `yanshuqi:user:basic:{user_id}` | `BasicUserProfileVO` JSON | 600s | BatchGetBasicProfiles 未命中回源后 | 资料写路径统一失效 |
| `yanshuqi:user:profile:{user_id}` | `RecommendUserProfileVO` JSON | 600s | BatchGetRecommendProfiles 未命中后 | 同上 |
| `yanshuqi:user:status:{user_id}` | `UserAvailableVO` JSON | 600s | CheckUserAvailable 未命中后 | 同上 |
| `yanshuqi:user:profile_view:{user_id}` | 资料视图（预留） | 600s | 当前读路径多直查 DB | 同上 |

**未引入** `yanshuqi:user:home_card:{self}:{target}`：target 资料更新时无法精准失效 self-target 组合 key。

配置：`app.user-cache.profile-ttl-seconds=600`（`UserCacheProperties`）。

### 写操作缓存失效表

| 写操作 | 失效 Key |
|---|---|
| ResolveOrCreate*（**仅 newlyCreated**） | basic / profile / status / profile_view |
| ResolveOrCreate*（复登） | 不失效 |
| UpsertOnboarding | 四类全删 |
| UpdateProfile | 四类全删 |
| ConfirmAvatarUpload | 四类全删 |
| BindUserPhoto | 四类全删 |

统一入口：`UserCacheInvalidationService.evictProfileCache` → `RedisKeyConstants.allUserProfileCacheKeys`。

### cache-aside 策略

1. 批量读 Redis（`CacheSafeExecutor.safeMultiGet`）。
2. 命中直接使用；未命中批量 IN 查 DB。
3. Service 层合并后 `put*` 写回 Redis。
4. **Redis 不是 source of truth**；写库成功后删 key。

### 降级策略

| 场景 | 行为 |
|---|---|
| get 失败 | warn 日志，视为全部 miss，回源 DB |
| set 失败 | warn 日志，不影响 gRPC 返回 |
| delete 失败 | warn 日志，不回滚 DB 事务 |
| 反序列化失败 | warn + 删除坏 key，回源 DB |

**禁止**：`FLUSHDB` / `FLUSHALL`；`CacheSafeExecutor` 过滤危险 key 名。

## 异常体系

### 核心类

- `UserBizException`：携带 `UserErrorCode`
- `UserGrpcStatusMapper`：errorCode → gRPC `Status`（分层：参数→INVALID_ARGUMENT，身份→UNAUTHENTICATED，不存在→NOT_FOUND，不可用→PERMISSION_DENIED，对象存储→UNAVAILABLE，冲突→ABORTED）
- `UserGrpcExceptionAdvice`：全局转换，未知异常 → `INTERNAL_ERROR`（不泄露堆栈）

### USER-09 错误码与 gRPC Status（节选）

| 域 | errorCode | Status |
|---|---|---|
| Auth | INVALID_DEVICE_ID / PLATFORM / PHONE / SMS_CODE | INVALID_ARGUMENT |
| Auth | INVALID_THIRD_PARTY_IDENTITY | UNAUTHENTICATED |
| Auth | USER_CONCURRENT_CONFLICT | ABORTED |
| Profile | INVALID_NICKNAME / GENDER / BIRTHDAY / AGE / HEIGHT / BIO | INVALID_ARGUMENT |
| Profile | PROFILE_NOT_FOUND | NOT_FOUND |
| Upload | AVATAR_PRESIGN_FAILED / AVATAR_OBJECT_STAT_FAILED | UNAVAILABLE |
| Upload | AVATAR_OBJECT_NOT_BELONG_TO_USER | PERMISSION_DENIED |
| HomeCard | TARGET_USER_UNAVAILABLE | PERMISSION_DENIED |
| HomeCard | TARGET_USER_NOT_FOUND | NOT_FOUND |
| 通用 | USER_BANNED / USER_DISABLED | PERMISSION_DENIED |
| 通用 | INTERNAL_ERROR | INTERNAL |

完整表见 `USER_SERVICE_SWAGGER_GOVERNANCE.md` 与 `UserGrpcStatusMapper`。

## 日志

### 禁止明文打印

`phone`, `smsCode`, `idToken`, `pushToken`, `deviceId`, `refreshToken`, `accessToken`, `presignedUrl`, `password`, `passwordHash`, `identityHash`。

### 允许打印

`user_id`, `identity_type`, `platform`, masked_phone, masked_device_id, `object_key`（缩写）, `error_code`, `grpc_method`, `cost_ms`。

工具：`SensitiveLogUtil`, `LogMaskUtil`, `IdentityHashService.maskDeviceIdForLog`。

### 慢调用日志（SlowCallLogger）

- 阈值：**500ms**
- **USER-09 覆盖**：resolveOrCreateDeviceUser/Phone/ThirdParty, upsertOnboarding, getUserProfileView, updateProfile, presignAvatarUpload, confirmAvatarUpload, getHomeCardProfile，及 register/verifyLogin/bindPhoto/批量查询
- 字段：`method`, `costMs`, `success`, `errorCode`, `userId`（白名单，不打印请求体）
