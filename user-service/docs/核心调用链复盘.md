# user-service 核心调用链复盘

按真实代码执行顺序整理。gRPC 层仅做参数转换，业务在 Service，单表访问在 Manager。

---

## Register

```
mobile-gateway / 调用方
→ UserAuthGrpcService.register()
→ RegisterRequest → RegisterCommand
→ UserAuthServiceImpl.register()
  → 1. validateRegisterCommand
  → 2. IdentityHashService 归一化 + hash（不写日志明文）
  → 3. UserAuthIdentityManager.findByIdentityTypeAndHash（幂等）
  → 4. BusinessIdGenerator 生成 userId/authId/profileId/settingId
  → 5. UserManager.createUser
  → 6. UserAuthIdentityManager.createIdentity（BCrypt password_hash）
  → 7. UserProfileManager.createDefaultProfile
  → 8. UserSettingsManager.createDefaultSettings
→ RegisterResult → RegisterResponse
```

**DB**：写 4 表。**Redis**：无。

---

## VerifyLogin

```
调用方
→ UserAuthGrpcService.verifyLogin()
→ VerifyLoginRequest → LoginCommand
→ UserAuthServiceImpl.verifyLogin()
  → 1. validateLoginCommand + 设备校验
  → 2. IdentityHashService 归一化 + hash
  → 3. UserAuthIdentityManager.findByIdentityTypeAndHash
  → 4. PasswordHashService.matches
  → 5. UserManager.findByUserId + 账号状态校验
  → 6. push_token → hash；device_fingerprint 规范化
  → 7. UserDeviceManager upsert
  → 8. UserManager.updateLastLoginAt + UserAuthIdentityManager.updateLastLoginAt
→ LoginResult → VerifyLoginResponse
```

**DB**：读 3 表，写 2 表。**Redis**：无。

---

## UpdateProfile

```
调用方
→ UserProfileGrpcService.updateProfile()
→ UpdateProfileRequest → UpdateProfileCommand
→ UserProfileServiceImpl.updateProfile()
  → 1. ProfileFieldValidator.validateAndNormalize
  → 2. UserManager.findByUserId + 账号状态校验
  → 3. UserProfileManager.findByUserId
  → 4. ProfileCompletionCalculator.calculate
  → 5. UserProfileManager.updateProfile
  → 6. ProfileStatusResolver.resolve → UserManager.updateProfileStatus
  → 7. UserCacheInvalidationService.evictProfileCache（失败不回滚）
→ UserProfileDetailVO → UpdateProfileResponse
```

**DB**：读写 users + user_profiles。**Redis**：删除 basic/profile/status。

---

## BindUserPhoto

```
调用方
→ UserProfileGrpcService.bindUserPhoto()
→ BindUserPhotoRequest → BindPhotoCommand
→ UserPhotoServiceImpl.bindUserPhoto()
  → 1. 参数校验 + PhotoObjectKeyValidator
  → 2. UserManager / UserProfileManager 查询 + 状态校验
  → 3. 头像：UserPhotoManager.disableCurrentAvatar → create/update photo
  → 4. UserProfileManager.updateAvatarKey（仅 AVATAR）
  → 5. ProfileStatusResolver → UserManager.updateProfileStatus
  → 6. UserCacheInvalidationService.evictProfileCache
→ BindPhotoResult → BindUserPhotoResponse
```

**DB**：写 user_photos，可能写 user_profiles + users。**Redis**：删除三 key。

---

## BatchGetBasicProfiles

```
下游服务
→ UserProfileGrpcService.batchGetBasicProfiles()
→ BatchGetBasicProfilesRequest → BatchGetBasicProfilesQuery
→ UserProfileQueryServiceImpl.batchGetBasicProfiles()
  → 1. BatchUserIdsValidator（去重、1～100）
  → 2. UserProfileCacheService.getBasicProfiles（Redis basic）
  → 3. 未命中：UserManager.listByUserIds
           + UserProfileManager.listByUserIds
           + UserPhotoManager.listEnabledApprovedAvatarsByUserIds
  → 4. Service 层合并 + UserAvailabilityEvaluator
  → 5. UserProfileCacheService.putBasicProfiles
  → 6. 按顺序返回，include_unavailable 过滤
→ List<BasicUserProfileVO> → BatchGetBasicProfilesResponse
```

**DB**：只读三表 IN 查询。**Redis**：cache-aside 读 + 写。

---

## BatchGetRecommendProfiles

```
下游服务
→ UserProfileGrpcService.batchGetRecommendProfiles()
→ BatchGetRecommendProfilesQuery
→ UserProfileQueryServiceImpl.batchGetRecommendProfiles()
  → Redis profile cache → 未命中三表批量读 → 合并 VO → 写 profile cache
→ RecommendUserProfileVO 列表 → Response
```

**不做推荐算法、不排序。**

---

## CheckUserAvailable

```
下游服务
→ UserProfileGrpcService.checkUserAvailable()
→ CheckUserAvailableQuery
→ UserProfileQueryServiceImpl.checkUserAvailable()
  → Redis status cache → 未命中 UserManager.listByUserIds
  → UserAvailabilityEvaluator → 写 status cache
→ UserAvailableVO 列表 → Response
```

**单用户不可用体现在 `available=false` + `reason`，不导致整批失败。**
