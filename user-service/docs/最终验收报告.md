## 模块定位

user-service 是 ChatVibe / Dating App 的**用户域唯一数据源**，负责用户注册、登录校验、资料维护、头像/相册 object key 绑定、设备记录、批量资料只读查询与用户可用性判断。下游服务（match、im、post 等）**禁止直连 user_center 数据库**，只能通过 gRPC 获取用户资料快照。

本模块**不签发 JWT**、不提供 gateway REST、不做推荐算法、不上传图片、不生成 presigned URL。
